成績如何互通： 老師與學生須開啟同一資料夾／同源網址（例如 GitHub Pages 的 /qdcs/）並用同一瀏覽器設定檔，提交後成績會寫入共用的 localStorage，老師「成績分析」即可看見。 若換電腦／換瀏覽器：學生提交後「複製作答 JSON」或下載檔案，老師在成績區「匯入作答 JSON」。

快速開始

  1. 老師開 teacher.html → 載入示範卷 BIODEMO 或自建卷
  2. 複製學生連結：student.html#q=分享碼
  3. 學生作答提交 → 老師重新整理「成績分析」
